# Анализ объявлений о продаже автомобилей с пробегом (Drom, Санкт-Петербург)

Проект собирает объявления о продаже подержанных автомобилей с сайта auto.drom.ru по Санкт-Петербургу, сохраняет их в базу SQLite и анализирует с помощью агрегирующих запросов на SQLAlchemy и pandas.

## Какие данные собираются

Из каждого объявления парсер извлекает:

- марку и модель автомобиля;
- год выпуска;
- цену в рублях;
- объём двигателя в литрах и мощность в л.с.;
- тип топлива (бензин, дизель, гибрид, электро);
- тип коробки передач (АКПП, механика, робот, вариатор);
- тип привода (передний, задний, 4WD);
- пробег в километрах;
- ссылку на объявление.

В выборку вошло 1000 объявлений о машинах с пробегом. Если в объявлении какая-то характеристика не указана, в базе она сохраняется как `NULL`.

## Структура проекта

- `parser.py` — сбор данных с сайта (requests + BeautifulSoup); результат записывается в `drom_spb.csv`.
- `db.py` — описание таблицы `cars`, подготовка данных из CSV, их загрузка в SQLite и подключение к базе `drom.db`.
- `PDA_Lab1.ipynb` — пять агрегирующих запросов; выполняются в Google Colab.
- `drom_spb.csv` — собранные данные в исходном виде.
- `drom.db` — готовая база SQLite.
- `requirements.txt` — список необходимых библиотек.

## Установка

Нужен Python 3.10 или новее.

Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Порядок работы

Все команды выполняются из корневой папки проекта.

1. **Сбор данных.** Запустите парсер:

   ```bash
   python parcer.py
   ```

   Результат сохраняется в файл `drom_spb.csv`.

2. **Загрузка в базу данных.** Выполните:

   ```bash
   python db.py
   ```

   Если файла `drom.db` нет, он будет создан вместе с таблицей `cars`. Идентификатором записи служит номер объявления, взятый из ссылки. Благодаря этому повторная загрузка не создаёт дубликаты: у уже известных объявлений обновляются значения, новые объявления добавляются.

## Агрегирующие запросы

1. Топ-10 марок по числу объявлений со средней ценой и средним пробегом.
2. Средняя цена и пробег по возрастным группам автомобилей (до 2010, 2010–2014, 2015–2019, 2020 и новее).
3. Количество объявлений и средняя цена для сочетаний «тип топлива — коробка передач» в виде сводной таблицы.
4. Средняя цена за одну лошадиную силу по маркам.
5. Медианная и средняя цена по маркам.

Запросы строятся средствами SQLAlchemy и сырого SQL, результаты читаются в pandas DataFrame.

## Таблица `cars`

| Поле | Назначение |
| --- | --- |
| `listing_id` | Номер объявления на Drom, первичный ключ |
| `brand` | Марка (из ссылки, латиницей в нижнем регистре, например `land_rover`) |
| `model` | Модель (из ссылки, например `hilux_pick_up`) |
| `year` | Год выпуска |
| `price` | Цена в рублях |
| `volume_l` | Объём двигателя, л |
| `power_hp` | Мощность, л.с. |
| `fuel` | Тип топлива |
| `transmission` | Коробка передач |
| `drive` | Тип привода |
| `mileage_km` | Пробег, км |
| `url` | Ссылка на объявление |
| `scraped_at` | Время последней загрузки записи в базу |
